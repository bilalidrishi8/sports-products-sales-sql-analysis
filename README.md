# 🏆 Sports Products Sales SQL Analysis

## 📌 Project Overview

This project is an end-to-end SQL analysis of a Sports Products Sales dataset using PostgreSQL. It demonstrates database design, data import, data cleaning, exploratory data analysis (EDA), and business-driven SQL queries to uncover valuable sales insights. The project covers beginner, intermediate, and advanced SQL concepts commonly used by Data Analysts and Business Intelligence professionals.

---

## 🎯 Project Objectives

- Analyze sports product sales performance.
- Identify top-selling products and retailers.
- Evaluate sales across regions, states, and cities.
- Measure operating profit and operating margin.
- Discover sales trends over time.
- Solve real-world business problems using SQL.
